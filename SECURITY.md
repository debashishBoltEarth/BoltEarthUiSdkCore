# Security Policy

The Bolt.Earth SDK is actively maintained by the Bolt.Earth engineering team.

If you discover a potential security vulnerability, privacy issue, or sensitive exposure related to the SDK, please report it responsibly to:

security@bolt.earth

Please do not publicly disclose security vulnerabilities before they have been reviewed and addressed by the Bolt.Earth team.

When reporting a security issue, please include:
- A description of the issue
- Steps to reproduce the behavior
- Affected platform(s) and SDK version
- Any relevant logs or screenshots

We appreciate responsible disclosure and will investigate all legitimate reports as quickly as possible.
